# fruit-collector

A fruit-collecting game where the player controls a basket to catch falling fruit. Fruits (apple, banana, melon, orange, pineapple) fall from the top of the screen. Score is tracked and a trophy image shows the reward. Clean JS module structure with separate form.js, game.js, and player.js files.

## Tech Stack

- **p5.js** — canvas-based creative coding library
- **p5.play.js** — sprite and collision support for p5.js

## How to Run

Open `index.html` in a browser — no build step required. All libraries are vendored in the repo.
